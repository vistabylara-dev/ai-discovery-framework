# AI Discovery Framework Overview

## Introduction

The AI Discovery Framework is an open technical framework created by Vista by Lara to help developers, businesses, and digital agencies build websites that are easier for modern AI systems and search engines to understand.

The framework focuses on technical implementation rather than marketing theory. It documents practical methods for improving semantic clarity, structured data, entity relationships, machine-readable resources, and information architecture.

As AI-powered search experiences continue to evolve, websites benefit from presenting information in ways that are easier for automated systems to interpret. This repository explores implementation patterns that support that goal.

---

# Vision

Our vision is to create an open reference library that documents modern techniques for building AI-ready websites using transparent, standards-based technologies.

The framework combines concepts from:

- Structured Data

- Entity-first information architecture
- Technical SEO
- Machine-readable documentation
- API design

# Core Principles

Every implementation within this repository follows several principles.

## 1. Entity First

Every important concept should exist as a clearly defined entity.

Examples include:

- Organization
- Person
- Product
- Service
- Place
- Article
- FAQ
- Event

Relationships between entities should be explicit whenever possible.

---

## 2. Structured Data

Machine-readable structured data provides additional context that complements visible page content.

Examples include:

- Organization
- WebSite
- LocalBusiness
- Service
- FAQPage
- Article

---

## 3. Semantic Architecture

Information should be organized around topics and relationships instead of isolated keywords.

A clear information hierarchy can help both users and automated systems understand how content fits together.

---

## 4. Machine-Readable Resources

Modern websites often expose structured resources such as:

- robots.txt
- sitemap.xml
- JSON-LD
- OpenAPI
- llms.txt

These resources help automated systems discover and interpret website content.
