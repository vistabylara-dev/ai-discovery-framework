# Entity SEO

## Overview

Entity SEO is the practice of organizing website information around clearly defined entities rather than relying only on keywords.

An entity is a uniquely identifiable person, organization, place, service, product, event, or concept.

Modern search technologies increasingly use entities and their relationships to understand information, provide context, and improve search quality.

---

# Why Entities Matter

Traditional SEO often emphasized keywords.

Entity SEO emphasizes meaning.

Instead of asking:

"What keywords should this page contain?"

Entity SEO asks:

"What real-world entity does this page represent?"

Examples include:

- Organization
- Person
- Service
- Product
- Place
- Article
- FAQ
- Event
- Category

Every page should have a clearly defined primary entity.

# Primary Entity

Each page should answer one simple question:

"What is this page primarily about?"

Examples:

Home Page

Primary Entity:

Organization

Service Page

Primary Entity:

Service

Article

Primary Entity:

Article

Author Page

Primary Entity:

Person

FAQ

Primary Entity:

FAQPage

Keeping one primary entity per page improves clarity.

These relationships enrich context while maintaining a clear primary focus.

# Summary

Entity SEO focuses on organizing information around real-world concepts instead of isolated keywords.

A clear entity model improves consistency, supports structured data, and provides a stronger semantic foundation for modern websites.

The techniques documented in this repository are intended to improve technical clarity and information architecture using open web standards.
